# 市町村クイズ

GitHub Pages 用の静的サイトです。ZIPを展開し、すべてのファイルを同じ階層へ配置してください。

## 主な機能

- 47都道府県から回答
- 同名自治体は存在する都道府県数に応じて複数回答
- 回答確定前は都道府県を何度でも選び直し可能
- 10問 / 20問 / エンドレス
- 市 / 町 / 村 / 全部
- 地方限定
- 10問・20問では同じ市町村名をゲーム中に再出題しない
- 初回スタート画面
- 終了画面（正解数・正答率・最長連続正解・間違えた問題）
- 同じ設定でもう一度 / 設定を変更して再スタート
- プレイ中の設定変更時はリセット確認
- Enter: 回答 / 次の問題、Esc: 設定を閉じる
- 回答後に人口・面積・人口密度・県内順位を表示
- GeoJSONによる県内位置表示

## 地図表示

- Web Mercator 相当の投影を使用し、緯度による縦横比の崩れを補正しています。
- 都道府県の主要陸域と離島を地理的に分け、遠い離島が本土側の縮尺を小さくしないようにしています。
- 離島自治体が出題された場合は、その自治体を含む島側へ自動フォーカスします。
- 同名自治体が2件以上の場合は、各回答カードを縦に並べ、カード内は地図を左・情報を右に配置します。

## ファイル

- `index.html` — UI / CSS
- `quiz.js` — ゲーム状態・設定・出題・採点・終了画面
- `map-loader.js` — GeoJSON読込・投影・離島を考慮した表示範囲計算
- `municipalities.js` — 市町村の基本データ
- `map_*.geojson` — 地方別の軽量行政区域データ

## データ

- 行政区域: 国土数値情報 N03（2026-01-01）
- 面積: 国土地理院（2026-04-01）
- 人口: 2026-01-01 の住民基本台帳人口を起動時に取得。取得できない場合は `municipalities.js` 内の同梱値を使用します。

## 東京都の特別区

東京都23区は地図背景として `map_53.geojson` に含めていますが、`municipalities.js` には含めていないためクイズには出題されません。東京都の市町村を表示する際、23区も東京都本土の背景として表示されます。
