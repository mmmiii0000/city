# 市町村クイズ

GitHub Pages 用の静的サイトです。ZIPを展開し、すべてのファイルを同じ階層へ配置してください。

## 主な機能

- 47都道府県から回答
- 同名自治体は存在する都道府県数に応じて複数回答
- 回答確定前は都道府県を何度でも選び直し可能
  - 1回答問題: 別の都道府県を押すと即座に置換
  - 複数回答問題: 選択済み県を押すと解除。全枠選択後に別県を押すと最後の枠を置換
- 10問 / 20問 / エンドレス
- 市 / 町 / 村 / 全部
- 地方限定
- 10問・20問では同じ市町村名をゲーム中に再出題しない
- 初回スタート画面
- 終了画面（正解数・正答率・最長連続正解・間違えた問題）
- 同じ設定でもう一度 / 設定を変更して再スタート
- プレイ中の設定変更時はリセット確認
- Enter: 回答 / 次の問題、Esc: 設定を閉じる
- 回答後に人口・面積・人口密度・県内順位を表示

## 地図の高速化

- 問題が表示された時点で、その問題のGeoJSON読込・県境処理・SVG生成を開始します。
- 完成したSVGはメモリにキャッシュされ、回答時はキャッシュから即表示します。
- 10問 / 20問では、残り問題に必要な地方GeoJSONもブラウザのアイドル時間に先読みします。
- 次の2問分はSVGまで先行生成します。
- 一度読み込んだ地方GeoJSONは同じゲーム中に再取得しません。

## 地図表示と離島

- Web Mercator 相当の投影を使用し、高緯度地域を含め全国で縦横比を補正しています。
- 本土・本島側の問題では、遠い離島を通常の縮尺計算から外すため、都道府県本体が小さくなりません。
- 離島自治体が出題された場合は、本土・本島側を通常の縮尺で残しつつ、対象離島を同じ地図内の拡大インセットで表示します。
- これにより「離島だけ」ではなく、本体とセットで確認できます。

## レイアウト

- クイズ枠は回答ボタンの位置で自然に終了し、ANSWER側の高さに引っ張られて伸びません。
- ANSWERは「情報が左・正方形の地図が右」です。
- 同名自治体が2件以上の場合は、この横長カードを縦に追加するためANSWER側だけが必要分だけ伸びます。
- 画面幅が1240px未満になると、クイズとANSWERが上下配置になります。

## ファイル

- `index.html` — UI / CSS
- `quiz.js` — ゲーム状態・設定・出題・採点・終了画面・地図先読み
- `map-loader.js` — GeoJSON読込・キャッシュ・SVGプリレンダリング・投影・離島表示
- `municipalities.js` — 市町村の基本データ
- `map_*.geojson` — 地方別の軽量行政区域データ

## データ

- 行政区域: 国土数値情報 N03（2026-01-01）
- 面積: 国土地理院（2026-04-01）
- 人口: 2026-01-01 の住民基本台帳人口を起動時に取得。取得できない場合は `municipalities.js` 内の同梱値を使用します。

## 東京都の特別区

東京都23区は地図背景として `map_53.geojson` に含めていますが、`municipalities.js` には含めていないためクイズには出題されません。東京都の市町村を表示する際、23区も東京都本土の背景として表示されます。
